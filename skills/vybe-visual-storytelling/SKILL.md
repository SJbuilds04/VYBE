# VYBE Visual Storytelling

A video is a sequence of promises and payoffs. Each scene must earn the next
second of attention. Load `references/composition.md` for frame layout.

## The hook (first 1.5 seconds)

Pick one: a **question** the viewer wants answered · a **bold claim** · a
**visual paradox** (something that shouldn't move, moving) · a **number** that
surprises · the **end result first**, then how. The hook is on screen at frame 0.

## Arcs by format

| Format | Arc |
| --- | --- |
| Product ad (15–45s) | hook → desire/problem → product reveal → 2–3 proofs (one per scene) → payoff line → CTA end card |
| Explainer (30–90s) | question → simple mental model → mechanism step by step → concrete example → takeaway |
| Social reel (10–30s) | pattern-interrupt hook → rapid value beats (1 idea/1–2s) → proof/number → loop-friendly CTA |
| Cinematic teaser | atmosphere → tension → glimpse → climax reveal → title → date/CTA |
| Documentary intro | place & time → human/quote → stakes → timeline → title card |
| Logo reveal | anticipation (parts) → assembly → impact → lockup → hold |
| Kinetic typography | statement → build (escalating scale/speed) → turn (contrast) → final word |

## Scene craft

- **One purpose per scene** (hook, context, build, proof, climax, resolve, CTA).
- **Show, then tell.** Visual first; text confirms; narration explains why.
- **Escalate.** Each scene a little bigger: scale, speed, color, sound.
- **Through-line.** A recurring object, shape, color or camera direction ties
  scenes together (the orb, the product, a line that keeps drawing).
- **Contrast creates rhythm.** Alternate dense/sparse, fast/slow, dark/light,
  close/wide.
- **Payoff the hook.** If you opened with a question, the last third answers it.

## Pacing

- Social: change something every 0.8–1.5s. Ads: every 1.5–3s. Explainers: let
  diagrams breathe 3–6s but keep a moving element.
- Front-load energy; put the strongest visual at ~60–70% (that is also the best
  thumbnail — set `storyboard.thumbnail`).
- End on a held frame (≥2s) the viewer can screenshot.

## Information design

- One number per scene, huge, with a short label.
- Diagrams build in the order the explanation needs them; label as you go.
- Comparisons side-by-side or as a before/after wipe, never as two paragraphs.
- Never invent facts, statistics or quotes for real subjects; use placeholders
  clearly marked for the user when the data is unknown.
